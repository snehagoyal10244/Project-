
# NOVARA – Luxury E-Commerce Platform

**Shop Smart. Live Better.**

NOVARA is a modern luxury e-commerce platform designed to provide customers with a premium and seamless online shopping experience.

## Features

- Modern and responsive UI
- User Registration and Login
- Product Listing and Product Details
- Product Search and Filtering
- Shopping Cart
- Wishlist
- Secure Checkout
- Order Management
- Backend API Integration
- MongoDB Database Integration

## Tech Stack

**Frontend:**
- React.js
- Vite
- CSS

**Backend:**
- Node.js
- Express.js
- MongoDB
- Mongoose

## Project Structure

- `frontend/` – Frontend application
- `backend/` – Backend API and server
- `README.md` – Project documentation

## Installation

1. Clone the repository:

   `git clone YOUR_GITHUB_REPOSITORY_URL`

2. Install frontend dependencies:

   `cd frontend`
   
   `npm install`

3. Start frontend:

   `npm run dev`

4. Install backend dependencies:

   `cd backend`
   
   `npm install`

5. Start backend:

   `npm start`
